## 本轮修改

1. **保存时借用只读列，替代完整内存副本。** v6 序列化通过共享锁读取已有 StringPool 和数组。数据列写完就释放锁，不把 fsync 和 rename 阶段包含在阻止修改的区间内。
2. **给所有引擎修改入口增加统一等待门。** 文件更新在序列化期间排在引擎锁之外，避免共享锁实现的写者优先策略连带阻塞搜索。数据本身仍由原有读写锁保护；更新会短暂延后，随后继续执行，不丢弃变更。
3. **流式 CRC 和直接读取字符串池。** CRC 支持沿用前一块校验值，去掉写盘时为校验分配大块缓冲及重新读文件的过程；加载也直接读入最终 buffer/entry 数组。增加分节文件边界、池条目边界检查，以及 fsync/fclose 失败处理。
4. **路径映射改用紧凑 B-tree。** 继续保存哈希和编号、核对真实路径，碰撞处理与去重语义保持。使用已经由 RE2 引入并安装的 Abseil；Makefile、Xcode 和中英文构建文档补齐直接依赖，没有额外下载新库。
5. **及时释放已用完的临时列。** 第二阶段建索引、写时复制压缩在相应列处理完成后提前释放快照数组。
6. **最近文件缓存使用有界堆。** 只保留最优的 200 项，不再为所有数百万条记录分配时间/编号临时数组；时间相同时按原缓存比较器的编号规则确定顺序。

磁盘格式未升级。旧版本读取器读取新版输出成功，新版本也能读取原有缓存；没有清空缓存、关闭索引功能或缩小扫描范围。

- 新增覆盖分块 CRC、时间戳并列的最近缓存顺序、保存时排队更新不阻塞搜索，以及写入失败后锁释放。既有碰撞、增删改、WAL、迁移、压缩和并发测试继续通过。
