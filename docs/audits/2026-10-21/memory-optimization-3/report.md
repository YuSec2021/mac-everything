# 内存优化与菜单栏搜索

## 本轮改动

- 名称和路径 trigram 倒排表使用 24 位记录编号；遇到超过 0xFFFFFF 的编号时，单个列表无损升级到 32 位。未改动磁盘 v6 格式。
- 两遍构建倒排表：先计数，再按准确容量一次分配，避免增长、缩容留下大量分配器高水位。
- GUI 查询保留 C++ 编号快照，首批仅生成 100 个结果对象；滚动时按页读取。原先会一次生成最多 10,000 个完整 Objective-C 结果对象。
- 快照保留所属引擎，并在共享锁内校验记录编号代数。删除会跳过墓碑；压缩或重新加载使旧快照失效，重新查询后再取页。页偏移按消耗的编号数推进，避免删除造成分页重复。
- 主窗口与菜单栏面板共用一个 SearchViewModel 和同一份索引，不重复启动扫描、HTTP 服务或建立第二份结果缓存。
- 左键菜单栏放大镜打开搜索面板，右键保留原设置菜单；面板支持自动聚焦、筛选、分页、Escape 关闭、切换主窗口。Search → Menu Bar Search… 提供辅助入口。
- 搜索结果改用原生 List，替代 ScrollView + LazyVStack。验收时旧懒加载列表的辅助功能滚动动作触发 SwiftUICore 断言；改用原生 List 后已通过滚动条分页和 Escape 返回主窗口验证。

## 固定数据对比

使用上一轮相同的本地 v6 快照：6,460,706 条记录，6,381,948 条存活记录。指纹见上一轮 fixture-sha256.txt。before.txt 使用上一轮 fixed-after 可执行文件，after.txt 使用本轮代码；顺序运行。单位为 MiB。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 名称倒排表有效容量 | 410.329 | 307.747 |
| 路径倒排表有效容量 | 278.978 | 209.234 |
| 两类倒排表合计 | 689.307 | 516.981 |
| 索引就绪进程物理内存足迹 | 1903.00 | 1882.89 |
| 保存并发查询/100 次更新阶段采样峰值 | 2431.52 | 2340.50 |
| 保存完成后重新载入存活记录数 | 6,381,948 | 6,381,948 |

倒排表减少约 172.33 MiB（25%），进程足迹减少约 20.11 MiB，采样峰值减少约 91.02 MiB。不能把结构容量减少直接当成进程常驻内存的等量下降。临时快照、查询候选集和分配器保留仍影响足迹。

首轮仅打包、沿用动态增长的实现曾使就绪足迹上升；本轮已经改为准确预分配，上表是最终实现的结果。

| 查询，最多 100 个结果 | 前平均 ms | 后平均 ms |
| --- | ---: | ---: |
| readme | 0.872 | 0.909 |
| *.swift | 0.243 | 0.253 |
| config | 1.396 | 1.984 |
| /Applications/ | 4.861 | 5.947 |
| size:>1mb | 1.995 | 2.286 |
| type:folder | 5.921 | 6.746 |

这是以少量解码/构建成本换取内存空间，并非查询全面提速。测试运行在用户当前使用的主机上，耗时会受其他应用影响。并发保存阶段最大查询耗时由 0.92 ms 到 31.41 ms，不能声称消除了长尾等待。GUI 的 10,000 条结果上限查询与上表 100 条查询不是同一种负载。

## 验证

- 最终核心快速回归：12,044 通过，0 失败。
- AddressSanitizer：Part 8 / 21 / 47 / 69 / 71，共 277 通过，0 失败。
- 独立 Objective-C++ 快照测试：结果顺序与旧接口一致；首两页、尾页、负数和极大偏移、删除、压缩失效、引擎替换后的快照生命周期均通过。运行方式：make test-bridge-snapshot。
- Release 构建通过。
- 原生 UI 实测：弹出面板自动聚焦；hello 返回 1,075 个匹配；滚动触发 100 → 200 条加载；Escape 关闭；主窗口保留相同查询。

## 范围与限制

本轮沿用已有的目录路径字典去重，没有改成父目录树，也未改磁盘格式。每次 GUI 查询仍保留原先最多 10,000 条编号的限制；全文结果仍最多 200 条。全文索引未启用，未实测实际全文结果；未完成所有多显示器/菜单栏自动隐藏组合的测试。最终构建已在解锁后重启验证。补充验收已完成：执行关闭主窗口，再通过 Search → Menu Bar Search… 打开弹出面板，输入项目路径与 ext:swift，返回 22 条结果；点击 Open main window 恢复主窗口，保留相同查询与结果。菜单栏面板已通过应用 Search 菜单入口验收；自动化工具未暴露系统菜单栏图标的直接点击节点，左右键分派由代码检查覆盖。
