# 借鉴 Everything 逆向结果优化 MacEverything

日期：2026-10-22。基线是上一轮目录树、大小写共享和 varint 名称倒排表的最终版本。

## 证据与实施范围

依据 docs/research/everything-1.4.1.1032/README.md 及原始 file-worker.asm。该样本是用户提供的 Everything 1.4.1.1032 x86 程序，仅做静态分析，没有执行 Windows 程序。

| 已核实的逆向线索 | 本轮借鉴方式 |
|---|---|
| 0x46bb97 分流单条件，0x46bbde 在扫描前选择操作码专用循环 | 单个 SUBSTRING 查询在工作线程进入循环前选择专用实现，大小写敏感与不敏感分别实例化；复杂表达式继续使用已有 AST |
| 0x46bc22 开始读取紧凑名称与长度并比较 | 名称先匹配，失败且语义要求路径时才还原父路径；glob、wholeword、wholefilename 等按实际需要读取字段 |
| 0x46bf74 等位置将记录指针写入工作线程结果缓冲 | 保留记录 ID 和排序字段；有限结果查询每个线程仅保留前 K 条，合并后使用原来的稳定排序规则 |
| 父目录关系、预处理与按块扫描的结构线索 | 在现有目录树上直接匹配组件，避免每个候选目录还原完整路径；保留取消检查 |

父目录原位匹配和 Top-K 堆是 MacEverything 的工程实现选择，不能声称已从该 Windows 样本中恢复了相同算法。样本也不足以证明应该删除所有倒排索引；本轮保留名称 trigram、扩展名和目录到记录的映射。

## 具体改动

- 合并原先候选大集合、候选小集合与完整扫描中重复的字符串评估循环。单 SUBSTRING 使用专用循环；其他表达式走通用 AST，RE2 继续使用各线程独立缓存。
- 单关键词已在名称中命中时，不再构造父路径或完整路径。大小写敏感查询仍使用原始字节，排序沿用原先的小写名称评分规则。
- DirectoryPool.matchesSegments 直接沿父节点读取小写组件，保留原有邻接、跨级和从右向左的规则。上下文大小写覆盖或长度截断时回退原有平坦字符串匹配，避免语义变化。
- 结果比较始终按 priority、pathLen、record ID 排序。普通有限查询使用每线程 K 大小的堆；全局前 K 必然包含于这些局部前 K 的并集。
- 纯类型、大小、时间条件的结果原先按 ID 排序，因此每个扫描段取得最早 K 条后即可结束；没有增加总命中计数承诺，显示结果上限保持不变。
- maxResults=0 仍返回全部结果。候选索引缓冲、输入索引和无限制查询的结果缓冲没有因 Top-K 而变成常数大小。
- 每个工作线程按相对起点定期检查查询代数，避免不对齐的分段跳过取消检查。

## 查询内存峰值

独立进程载入同一快照并完成 Phase 2，首次执行一个最多返回 10,000 条结果的查询。另一个线程每 1 ms 采样 Mach 物理内存足迹；数值为采样峰值，不保证捕获每个瞬时尖峰。

| 查询 | 前耗时 ms | 后耗时 ms | 前额外占用 MiB | 后额外占用 MiB | 前进程峰值 MiB | 后进程峰值 MiB |
|---|---:|---:|---:|---:|---:|---:|
| `size:>=0` | 20.95 | 1.00 | 179.24 | 2.36 | 1443.69 | 1266.77 |
| `!zzzz-memory-check-absent-12938` | 51.22 | 32.56 | 187.16 | 2.82 | 1451.41 | 1269.52 |

就绪足迹在最终性能进程中为 1267.20 → 1259.88 MiB。索引结构容量一致，这约 7 MiB 的差异不作为常驻数据压缩收益；本轮重点是减少查询临时分配和恢复上一轮压缩后的部分查询性能。

## 范围与限制

没有实现通用布尔成功/失败跳转图，没有改变 Unicode 或重音匹配语义，也没有取消名称索引。仍未达到 1 GiB 内的目标。无限制查询依然按请求保留所有命中；未测长期驻留、全盘重建、启用全文索引后的峰值，也未重复直接点击系统菜单栏图标的验收。

本轮没有更改磁盘编码和扫描器，没有执行或发布 Windows 样本。

## 复现

profile.cpp 接收固定 v6 文件路径；query-memory.cpp 另接收查询文本。以 C++20、-O2 编译并链接项目原有 RE2、Abseil、CoreServices；性能脚本读取内部容量统计时添加 -fno-access-control。所有测试只读输入。基线源码位于 /tmp/maceverything-win-inspired-before/Core。
原始日志：tests.log、sanitizers.log、bridge.log、before.txt、after.txt、memory-*.txt、live-vmmap.txt。
