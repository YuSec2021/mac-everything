# 154：搜索面板的补全光标、列表刷新与预览层级

日期：2026-11-17

对应 [Issue #13](https://github.com/YuSec2021/mac-everything/issues/13)。版本保持 1.4.0（Build 4）。

- **Tab 补全**：通过 NSTextView 的编辑流程同步提交补全文本和光标位置，避免 `fil` 补全后紧接着输入 `X` 变成 `filXe:`。使用 UTF-16 选区，支持中文和 Emoji，保留原生撤销；输入法仍在组词时不接受补全。外部清空文本时将旧选区限制在有效范围。
- **结果可见区域**：结果替换、分页追加和搜索窗口重新成为 key window 时，待 SwiftUI 提交行更新后刷新当前列表的 AppKit 布局及可见行绘制。没有保留选中项的新查询返回首行；保留选中项时定位到该项，分页和同一查询的索引刷新保留有效滚动位置。使用独立的结果修订号识别同样数量的结果替换；选中行的滚动定位延后到行更新后执行。沿用原生 List，不重建数据源；高亮设置的查找范围收窄到所属列表。
- **Quick Look**：打开预览后按当前搜索窗口的实际层级置前，覆盖菜单栏 popover 和备用浮动面板；普通关闭、系统关闭和控制权结束时恢复原始层级及 popover 的 transient 行为。
- About 版本说明和变更索引同步更新。

验证使用 `make test-search-ui`，直接加载生产搜索输入框、列表呈现辅助视图和 Quick Look 控制器，并用独立测试模型避免启动文件索引。覆盖补全后立即输入、中文/Emoji 和长文本、普通高亮保留选区、清空、首屏结果、分页、相同数量的新查询、重开窗口，以及两类窗口的预览层级和关闭恢复。

Debug 和 Release 构建通过。Release 实机检查确认 `fil` → Tab → `X` 得到 `file:X`，10,000 条匹配的首屏自动显示、分页追加与查询切换正常，Quick Look 可打开和关闭，About 显示 1.4.0（Build 4）及本次说明。

本机复现了原有补全插入位置错误；列表对照测试确认旧实现会保留新查询之前的滚动位置。Issue 中“有结果但整个列表空白，滚动才恢复”的完整现象在本机尚未稳定复现，当前针对可见区域和绘制刷新进行修复，仍需在报告者的 macOS 环境确认。
