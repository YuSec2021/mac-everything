# 150：菜单栏搜索界面改为液态玻璃风格

日期：2026-11-06

按 [149](149-liquid-glass-prototype.md) 的设计原型重新设计菜单栏搜索面板和浮动面板：

- 面板固定为深色外观，背景为系统材质上叠加藏蓝渐变和两处柔和高光。
- 顶部改为品牌区（图标、名称和副标题），设置菜单与关闭按钮改为圆形玻璃按钮；浮动面板隐藏系统窗口按钮，避免与品牌区重叠。
- 搜索框改为带高光边缘的玻璃胶囊，聚焦时显示柔和的强调色描边；搜索语法帮助改为圆形按钮，已启用的搜索选项标记使用同一强调色。
- 结果列表中的文件图标放入玻璃底块；选中行使用渐变高亮代替系统选中色，匹配文字使用新的强调色。
- 空状态改为玻璃图标块和更醒目的标题，初始状态提示 ↓ 浏览结果和 Space 预览。
- 状态栏的 Live 指示点带发光效果，已索引文件数按千位分隔显示。

新增 `GlassStyle.swift` 集中定义颜色和玻璃样式。搜索、选择、键盘导航、Quick Look 和右键菜单行为不变；面板尺寸仍为 640×500。版本号和构建号未修改。
